MH DAILY SALES — Android APK project

This project wraps the existing Shop_Daily_Sales_Compact_Shop.html in an Android WebView.
It includes local HTML storage, Android file selection for JSON backup restore, native Downloads saving for backup JSON, and Android print-to-PDF for sales reports.

Build:
- Requires Android SDK and JDK 17.
- Open this folder in Android Studio and build the debug APK, OR push the project to a GitHub repository and run the included Actions workflow named "Build MH Daily Sales APK".
- APK output: app/build/outputs/apk/debug/app-debug.apk

Important:
- This is a project source ZIP, not a compiled APK.
- Test on your phone before relying on it for business records. Use Download Backup regularly.
